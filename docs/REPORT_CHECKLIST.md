# Checklist del Final Project Documentation Report

## Repositorio
- [ ] Organización pública de GitHub.
- [ ] Repositorio público del Project Report.
- [ ] README.md como archivo principal.
- [ ] Markdown como formato fuente.
- [ ] Todos los integrantes tienen commits reales.
- [ ] GitFlow documentado y aplicado.
- [ ] Conventional Commits aplicado.
- [ ] Semantic Versioning aplicado a releases.

## Informe
- [ ] Carátula completa.
- [ ] Registro de Versiones actualizado.
- [ ] Collaboration Insights actualizado por entrega.
- [ ] Tabla de contenidos.
- [ ] Student Outcome actualizado.
- [ ] Capítulos requeridos según la entrega.
- [ ] Conclusiones actualizadas.
- [ ] Bibliografía APA 7.
- [ ] Anexos actualizados.

## Artefactos
- [ ] User Stories redactadas como texto/tablas.
- [ ] Acceptance Criteria redactados, no sólo capturas.
- [ ] Product Backlog redactado en el informe.
- [ ] Sprint Backlogs redactados en el informe.
- [ ] UX artifacts insertados como imágenes + explicación.
- [ ] Diagramas insertados como imágenes + explicación.
- [ ] Fuentes editables de diagramas guardadas cuando aplique.

## Exposición
- [ ] Todos los integrantes aparecen ante cámara.
- [ ] Se muestran los artefactos correspondientes al hito.
- [ ] Se utiliza presentación PowerPoint/Keynote.
- [ ] Video final único y editado.
- [ ] Duración máxima: 30 minutos.
- [ ] URL incluida en Anexos > Videos de Exposiciones.

## Nomenclatura de entregables
- [ ] Report: `upc-pre-202620-1asi0572-<NRC>-<startup>-report-<avn/tbn>.pdf`
- [ ] Keynote: `upc-pre-202620-1asi0572-<NRC>-<startup>-keynote-<avn/tbn>.pptx/.pdf`
- [ ] Performance: `upc-pre-202620-1asi0572-<NRC>-<startup>-performance-<avn/tbn>.docx/.pdf`
- [ ] Expo: `upc-pre-202620-1asi0572-<NRC>-<startup>-expo-<avn/tbn>.mp4`
